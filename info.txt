In MongoDB we have:

Database
   ↓
Collection
   ↓
Documents


-------------------------------------

Qdrant has:

Cluster
   ↓
Collection
   ↓
Points

A point is basically:
vector + payload

For example:
{
    "id": "chunk-123",
    "vector": [0.12, -0.43, 0.81, ...],
    "payload": {
        "user_id": "user123",
        "kb_id": "kb456",
        "document_id": "doc789",
        "chunk_index": 3,
        "text": "Machine learning is..."
    }
}

     documents.py

       Document Loader

          Documents

             ▼

             │
             ▼
       SentenceTransformer
             │
             ▼
